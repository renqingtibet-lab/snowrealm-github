# 雪域藏地好物 · SnowRealm

旅游摄影 · 藏地特产 · 信息技术

## 后台使用说明

1. 打开 `admin.html`
2. 输入密码进入（密码：`rqdj123456`）
3. 修改内容后点「保存到本机」可在本浏览器预览
4. 要让**所有人**看到改动：
   - 进入「同步到源文件」选项卡
   - 点击对应按钮生成可粘贴代码
   - 打开对应 `.html` 文件，替换旧的数据变量
   - 提交并推送到 GitHub

## 安全

- `admin.html` 已加密码门禁，不知道密码的人无法进入后台。
- 如需更换密码，修改源码顶部的 `ADMIN_PASSWORD` 即可。
