同步到 .html 源文件（永久上线）

  2. 点击对应按钮，生成可直接粘贴的 JS 代码
  3. 用编辑器打开对应的 .html 文件
  4. 搜索并找到旧的 let productsData = [ 或 const products = [ 整段，整段删除后粘贴新代码
  5. 保存文件 → 提交并推送到 GitHub 仓库
  6. 等待 1～2 分钟，线上网站即更新

使用说明

别人看不到后台：本页已加密码门禁。不知道密码的人打开 /admin.html 只会看到登录框，无法进入。

改密码：打开本文件源码，找到顶部的 ADMIN_PASSWORD，改成你自己的密码即可（建议复杂一点）。

改文字 / 改图片：在对应选项卡修改后点「保存到本机」，刷新前台即可预览（仅本机浏览器生效）。

换照片：新照片放入 images/ 或 images/photo/，在 JSON 里改 img 路径并保存。

永久上线：使用「同步到源文件」选项卡，生成代码 → 粘贴进对应 HTML → 推送到 GitHub。

防下载：前台已禁止图片右键与拖拽（无法完全防止截图）。
